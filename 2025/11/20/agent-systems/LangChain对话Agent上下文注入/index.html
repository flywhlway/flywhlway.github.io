一、核心架构设计

三层注入原则：

  1. System Prompt（不变） — 角色身份、能力边界、行为规则
  2. Memory（动态压缩） — 历史对话的摘要或滑动窗口
  3. Human Input（实时） — 当前轮次的用户输入
