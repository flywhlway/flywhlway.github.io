05 · Python 侧埋点：FastAPI + LangGraph/DeepAgents + mem0 + DeepSeek

Python 是 AI 执行面的主语言。本篇产出一个可复用的 telemetry.py 引导模块，实现：HTTP 层自动埋点、LLM 调用（DeepSeek，OpenAI 兼容端点）自动埋点、LangGraph 图执行埋点、mem0 手动埋点、日志与 Trace 关联、自定义业务指标。文档 09 的 Demo 直接复用本篇代码。

② openinference-instrumentation-langchain LangChain/LangGraph 链与图节点 Arize 维护、纯 OTel Span 输出、Langfuse/Tempo 均可消费

8. 日志与 Trace 关联验证

LoggingInstrumentor(set_logging_format=True) 后，标准 logging 输出自动带 trace_id：

同时 OTLP Logs 通道把结构化日志送入 Loki。验证互跳：

9. 常见坑位

坑 现象 解法
setup_telemetry 晚于框架 import LLM/图 Span 缺失 引导模块放在入口文件第一行
uvicorn 多 worker 指标重复/丢失 每 worker 独立初始化（默认即是）；聚合交给 Prometheus
①与③方案同装 每次 LLM 调用出两个 Span 只保留一套 LLM 埋点
流式响应 Token 统计缺失 usage 为空 请求带 stream_options={"include_usage": True}
asyncio 后台任务丢上下文 子 Span 变孤儿 Trace asyncio.create_task 前用 opentelemetry.context.attach 或把 span 上下文显式传入
忘记优雅退出 尾部数据丢失 进程退出前 trace.get_tracer_provider().shutdown()
