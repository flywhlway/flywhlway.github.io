Gemini CLI 核心概念与基础配置

概述

Gemini CLI 是 Google 官方推出的命令行 AI 工作流工具，连接你的开发工具，理解你的代码库，加速开发流程。支持大型代码库查询、从草图生成应用、自动化运维任务等功能。

系统要求

硬件环境

配置项 最低要求 推荐配置
处理器 Apple Silicon M1 Apple Silicon M3/M4/M5
内存 8GB 16GB+
存储 10GB 可用空间 SSD 50GB+

你的配置: MacBook M5 Pro 48GB 内存 ✅ 完美适配

软件环境

  • macOS 12.0+
  • Node.js 18.0+
  • npm 或 bun 包管理器
