配置属性详解

属性 类型 必需 描述
name string 是 扩展名称
version string 是 版本号
description string 否 描述
author string 否 作者
license string 否 许可证
repository string 否 仓库地址
contextFileName string 否 上下文文件名
mcpServers object 否 MCP 服务器配置
excludeTools string[] 否 排除的工具
plan object 否 计划目录配置
