Hooks 生命周期钩子配置

概述

Hooks 是 Claude Code 的生命周期钩子系统，可以在工具执行的特定阶段自动触发自定义操作。通过 Hooks，可以实现自动化工作流、安全检查、代码格式化等功能。

生命周期阶段

Hook 类型

Hook 类型 触发时机 典型用途
SessionStart 会话开始时 初始化环境、加载上下文
PreToolUse 工具执行前 安全检查、权限验证
PostToolUse 工具执行后 格式化、状态同步
Stop 响应结束时 持久化数据、清理资源

环境变量

Hooks 执行时可用的环境变量：

变量名 描述
CLAUDE_TOOL_FILE_PATH 当前操作的文件路径
CLAUDE_TOOL_NAME 当前执行的工具名称
CLAUDE_PLUGIN_ROOT 插件根目录
CLAUDE_PROJECT_ROOT 项目根目录
CLAUDE_SESSION_ID 当前会话 ID

配置最佳实践

1. 合理设置超时

2. 异步执行非关键操作

3. 清晰的描述

4. 错误处理

脚本应返回适当的退出码：

  • 0: 成功，继续执行
  • 1: 失败，阻止操作
