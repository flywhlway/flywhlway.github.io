Gemini CLI MCP 服务器深度配置

概述

MCP (Model Context Protocol) 是 Gemini CLI 的扩展机制，通过配置 MCP 服务器，可以连接数据库、调用 API、集成第三方服务等，大幅扩展 Gemini 的能力边界。

MCP 架构

配置位置

位置 文件路径 作用域
全局 ~/.gemini/settings.json 所有项目
项目 项目/.gemini/settings.json 当前项目
扩展 扩展/gemini-extension.json 扩展专属

配置结构

基础结构

完整配置属性

属性 类型 必需 描述
command string 是* 执行命令
args string[] 否 命令参数
env object 否 环境变量
cwd string 否 工作目录
timeout number 否 超时时间(ms)
trust boolean 否 是否信任
includeTools string[] 否 包含的工具
excludeTools string[] 否 排除的工具
url string 是* SSE URL
httpUrl string 是* HTTP URL

*至少需要 command、url 或 httpUrl 之一

常见 MCP 服务器推荐

服务器 用途 安装命令

常见问题

问题 1: 服务器启动失败

  • 检查命令路径是否正确
  • 检查环境变量是否设置
  • 检查依赖是否安装

问题 2: 工具不显示

  • 运行 /mcp refresh 刷新
  • 检查 includeTools 配置
  • 查看服务器日志

问题 3: 权限问题

  • 检查 trust 配置
  • 检查 mcp.allowed 白名单
