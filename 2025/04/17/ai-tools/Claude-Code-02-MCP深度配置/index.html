MCP 服务器深度配置指南

概述

MCP (Model Context Protocol) 是 Anthropic 推出的标准化协议，用于扩展 Claude Code 的能力边界。通过 MCP，Claude 可以连接数据库、调用 API、操作文件系统、控制浏览器等。

官方 MCP 服务器配置

GitHub MCP

功能:

  • 创建/更新/关闭 Issues 和 PR
  • 搜索代码和仓库
  • 管理分支和标签
  • 查看提交历史和文件内容

Supabase MCP

功能:

  • 执行 SQL 查询
  • 管理表结构
  • 操作认证用户
  • 存储文件管理

Memory MCP

功能:

  • 存储重要信息供后续会话使用
  • 创建知识图谱
  • 管理实体关系

Sequential Thinking MCP

功能:

  • 分步骤解决复杂问题
  • 思维链追踪
  • 推理过程可视化

Playwright MCP

功能:

  • 自动化浏览器操作
  • 网页截图和PDF生成
  • 表单填写和点击
  • E2E 测试

Context7 MCP

功能:

  • 获取最新的库文档
  • 代码示例查询
  • API 参考检索
