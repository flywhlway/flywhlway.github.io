一、概述

本文档详细描述了基础平台（BP）中云边协同技术方案。核心理念是将云端计算能力下沉到车端，实现云边协同和边缘自治，提升实时性，减少车云信号传输带宽及云端海量大规模计算。

二、核心设计理念

2.1 算力下沉

  • 将云端计算能力下沉到车端
  • 实现云边协同、边缘自治
  • 提升实时性

2.2 适用场景

场景 说明
预估里程 基于车端实时数据的里程预测
故障计算 车端故障实时诊断与预警
驾驶行为分析 驾驶习惯实时分析反馈
数据采集计算 车载数据的实时处理与上传

2.3 核心价值

  • 减少车云信号传输带宽
  • 降低云端海量大规模计算压力
  • 提升计算实时性

3.1 云端架构

3.2 通信层

云端与车端通过以下通道互联：

通道 方向 用途
车辆MQTT网关 云→车 任务调度与指令下发
车端Edge网关 车→云 车载计算结果上传
数采上传网关（结构化/非结构化） 车→云 原始数据上传

3.3 车端架构

四、Edge Engine 核心设计

4.1 云端 Edge Engine Cloud

管控面—负责算法和规则的管理与调度：

功能 说明
应用管理 边缘应用的生命周期管理
应用调度 将计算任务调度到车端
算法调优 基于反馈数据优化算法
模型训练 在云端训练AI模型
算法统计 算法效果评估与统计

4.2 车端 Edge Engine

数据面—负责实际的边缘计算执行：

功能 说明
任务管理 接收和管理云端下发的计算任务
日志 计算日志记录与上报
业务计算 疲劳驾驶、里程预估、故障计算等
数据接入 从Transport层获取原始数据

4.3 数据流路径

五、数据接入能力

车端数据池支持丰富的数据源：

数据类型 协议/格式 典型场景
Audio 音频流 语音交互
Video 视频流 智驾感知
Lidar 激光雷达 3D环境感知
CAN/LIN 车载总线 车身信号
SomeIP 以太网服务 SOA通信
DC/TP 诊断通信 故障诊断
ASF (SomeIP) 自适应服务 高级服务调用
Shadow 数字孪生 车辆状态影子

六、关键技术洞察

  1. 云边一体：Edge Engine在云端和车端采用统一架构，云端负责管控、车端负责执行
  2. 算力弹性：可根据车端算力灵活调度计算任务，实现算力的最优分配
  3. 数据闭环：车端计算→结果上传→云端分析→模型/策略优化→下发更新，形成完整闭环
  4. 多源接入：支持8种以上数据源类型，覆盖音视频、传感器、总线等全维度数据
  5. 实时性保障：通过边缘计算实现毫秒级响应，满足驾驶安全类场景需求
