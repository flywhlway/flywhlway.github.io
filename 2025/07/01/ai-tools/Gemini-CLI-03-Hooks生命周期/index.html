Gemini CLI Hooks 生命周期钩子

概述

Hooks 是 Gemini CLI 的生命周期钩子系统，可以在特定阶段自动触发自定义操作，实现自动化工作流、安全检查、上下文注入等功能。

生命周期架构

Hook 类型

Hook 类型 触发时机 典型用途
SessionStart 会话开始 初始化环境、加载配置
BeforeAgent Agent 执行前 注入上下文、加载记忆
BeforeToolSelection 工具选择前 过滤可用工具
BeforeTool 工具执行前 安全检查、权限验证
AfterModel 模型输出后 记录输出、格式化
AfterAgent Agent 执行后 验证结果、状态同步
SessionEnd 会话结束 保存记忆、清理资源
