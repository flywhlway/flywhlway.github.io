最佳实践

1. 单一职责

每个 Agent 专注于一个领域，避免功能重叠。

2. 明确接口

定义清晰的输入输出格式。

3. 适度并行

并行执行独立的任务，串行执行有依赖的任务。

4. 结果验证

验证 Agent 输出的有效性和一致性。

5. 容错处理

处理 Agent 执行失败的情况，提供降级方案。
