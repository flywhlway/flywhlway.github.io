第一部分：10 分钟快速上手

步骤 1：安装与登录（3 分钟）

  • 使用 GitHub / Google / 企业邮箱登录（==必须登录才能使用 AI 功能==）
  • 选择默认 Shell（推荐 zsh）

步骤 2：基础配置（2 分钟）

设置路径 推荐配置
Settings → Appearance → Theme 选择喜欢的主题（推荐 Dracula、Tokyo Night）
Settings → Appearance → Text → Terminal font 安装并选择 Nerd Font（见后文）
Settings → Features → Session → Startup shell 确认为 /bin/zsh

第八部分：问题排查速查

问题 1：终端显示乱码

原因 解决方案
未安装 Nerd Font 安装并选择 Nerd Font
字体选择错误 选择带 Nerd Font Mono 后缀的字体
主题冲突 切换到默认主题测试

问题 2：AI 功能无响应

原因 解决方案
未登录账号 重新登录 Warp 账号
网络问题 检查网络连接
API 限制 等待额度恢复或升级订阅

问题 3：SSH 后功能丢失

原因 解决方案
远程无 tmux 安装 tmux 或使用 Legacy 模式
Warpify 未启用 手动启用 Warpify
Shell 配置冲突 检查远程 ~/.bashrc

问题 4：输入卡顿

原因 解决方案
Shell 插件过多 禁用不兼容插件
历史记录过大 清理历史记录
字体渲染问题 切换到轻量字体

问题 5：命令补全失效

原因 解决方案
Shell 类型不支持 确认使用 zsh/bash/fish
配置文件错误 检查 DCS Hook 是否正确添加
权限问题 检查 Shell 配置文件权限
