Obsidian Agent Skills 最佳实践指南与实操手册

概述

Obsidian Agent Skills 是由 Kepano（Obsidian 创始人）开发的一套 Agent Skills 技能集，遵循 Agent Skills 规范，可被 Claude Code、Codex CLI 等 AI 代理直接调用。

核心价值

价值点 说明
AI 原生 让 AI 代理理解 Obsidian 特有语法和功能
规范化 遵循统一的 Agent Skills 规范
自动化 AI 可直接创建、编辑、管理 Obsidian 内容
跨平台 支持 Claude Code、Codex CLI、OpenCode 等多种 AI 工具

技能清单

技能名 用途 文件类型
obsidian-markdown Obsidian 风格 Markdown .md
obsidian-bases 数据库视图 .base
json-canvas 画布文件 .canvas

7.4 Base 与 Dataview 对比

维度 Bases Dataview
原生支持 ✅ Obsidian 1.8+ ❌ 需安装插件
语法 YAML 类 SQL
视图类型 表格/卡片/列表/地图 表格/列表/任务/日历
公式 内置函数 需学习 DQL
AI 友好 ✅ 结构化 YAML ⚠️ 需学习语法

推荐：优先使用 Bases，更易被 AI 理解和生成。

7.5 Canvas 使用场景

流程图 文本节点 + 带标签的边
