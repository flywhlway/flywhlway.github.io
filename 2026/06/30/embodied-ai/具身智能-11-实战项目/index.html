第十一篇 实战项目：Embodied Cloud Platform v0.2

蓝图（第十篇）落回代码。本篇把第三篇的遥测系统 v0.1 按参考架构升级为 v0.2：一个可以在你的 Mac 上 docker compose up 跑起来的最小 Embodied Cloud——补上身份鉴权、影子服务、模型 OTA 最小闭环、触发式录制回传、可观测与简易大盘。它刻意保持「一台笔记本可运行」的体量，但每个模块都是第四~十篇对应平面的可辩护缩影——写进简历后，面试官问到任何一个框，你都能向上展开到企业级设计（引用对应篇章），向下展开到代码。

11.0 项目定位与验收

11.0.1 v0.1 → v0.2 升级清单

能力 v0.1（第三篇） v0.2（本篇） 对应平面
接入 匿名 MQTT 用户名/密码 + 每机独立凭据（mTLS 留作 v0.3，给出配置位） 接入/安全面
设备 无 注册激活 API + 影子服务（desired/reported/delta） 设备面
OTA 模拟任务 真实模型 OTA 最小闭环：制品上传→校验和→任务下发→端侧下载验证→双槽切换→版本上报 OTA 面
数据 最新状态 SQLite 遥测入 SQLite 时序表 + 触发式 bag 片段回传 MinIO 数据面
任务 RobotTask 五类 保留 + 任务表全生命周期 + 租约超时回收 任务面
可观测 无 三键结构化日志 + /metrics + 简易大盘页 可观测面

11.0.2 验收标准（项目即证书）

  • 一条命令拉起 6 个容器；机器人注册激活后才被接受遥测
  • 影子收敛演示：云端改 desired.report_hz → 端侧 Parameter 生效 → reported 回归一致
  • 模型 OTA 全链路：上传「模型文件」→ 下发 → 端侧校验和验证 → 槽位切换 → 孪生显示新版本；坏校验和 → 拒绝安装并回执失败
  • 触发回传：注入 error_code → 端侧 bag 片段出现在 MinIO 对应分区
  • 租约回收：kill 云桥进程 → 任务超租约被标记回收
  • 大盘页可见：在线状态、电池曲线、任务列表、模型版本

11.1.2 Compose 全家桶（6 服务）

生产对照卡（每项注释指向篇章）：mosquitto→EMQX 集群（4.1）、FastAPI 单体→Spring Cloud 微服务分平面（10.3）、SQLite→PG+Redis+CH（4.1.5）、MinIO 单机→分发四级瀑布（4.3.4）。「简化点即产品化 backlog」（3.3.12）在 v0.2 延续。

11.3 核心新模块代码

11.3.1 影子服务（cloud/app/device.py 关键段）

11.3.2 端侧模型管理器（model_manager.py，双槽最小实现）

task_executor 的 ota 分支改为调用它：download/verify 阶段真实执行、install 即切槽、restart 阶段上报新版本进 reported——假任务变真闭环。坏校验和用「篡改 sha256 再下发」演示，拒装+失败回执即 9.3 验签闭环的可触摸版。

11.3.3 触发式录制（bag_trigger.py 思路段）

演示钩子：telemetry_agg 增加 error_code 参数——ros2 param set /telemetry_agg error_code 42 一条命令即可现场触发整条链路（影子 delta 也能改它：两条演示线交汇）。

11.3.4 租约回收（cloud/app/task.py 定时器）

云桥每次 Feedback 转发时刷新 lease_until（续租）——kill 云桥 30 秒后看任务被回收，租约语义眼见为实。

11.5.3 简历与面试用法

简历一句话：「设计并实现 Embodied Cloud Platform：机器人接入/影子/模型 OTA/触发回传/任务租约的最小闭环，架构对标企业级八平面参考架构（可现场演示）」。面试展开路径：大盘演示 2 分钟 → 被问任一模块 → 打开对应 docs/adr/ 与本书对应篇章的设计 → 讲「玩具版 vs 生产版」差异（每个简化点都有产品化答案）——作品的价值不在代码量，在每一行都可向上辩护。

11.6 本篇总结

11.6.1 核心结论

  1. v0.2 = 八平面的可运行缩影：目录即架构，简化点即 backlog，每个模块可向上辩护到企业设计。
  2. 六条验收即六个平面的最小闭环：激活准入、影子收敛、OTA 双槽、触发回传、租约回收、可观测。
  3. 影子/租约/双槽/元数据先行/分区命名——五个「玩具实现」承载了全书最重要的五个机制。
  4. 两周开发计划 + 五版 Roadmap：项目同时是学习验收物、简历作品与入职作战图。
  5. 3 分钟 demo 视频 + ADR 目录是面试的两件套：演示证明能做，ADR 证明会想。

11.6.2 本篇卡片索引

目录即架构 · 六条验收六个平面 · 五个玩具机制 · 每行代码可向上辩护 · demo 视频加 ADR 两件套
