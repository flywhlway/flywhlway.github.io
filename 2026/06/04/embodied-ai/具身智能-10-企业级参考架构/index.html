第十篇 企业级参考架构：Embodied Cloud Architecture v1

第四~九篇建成了九个能力面。本篇把它们收敛为一份白皮书级参考架构：八个平面的分层视图、四张部署视图、三条核心数据流、技术选型矩阵与六个 Ops 的流水线体系。定位：对外是你汇报与竞标的总蓝图，对内是落地路线与评审基准（与 4.11 Checklist 配套构成 M3 的完整交付物）。本篇是「收敛之篇」——几乎不引入新概念，只做结构化合龙，每节末尾以「索引六件套」形式给出回链而非重复展开。

10.2 数据流视图：三条主干流

10.2.1 遥测流（秒级，常开）

端侧聚合 5Hz → MQTT → Kafka → Flink（健康分/告警/QoS 事件）→ CH + 影子 →大盘/调度/灰度门禁（4.8.1）。SLA：端到大盘 P99 < 10s。

10.2.2 任务流（分钟~小时级，事务性）

订单 → Fleet 调度（孪生输入）→ Temporal 工作流 → RobotTask（MQTT）→ 端侧执行 → 回执/续租 → 闭单归档（4.7.6）。SLA：无人工闭单率 ≥ 目标值；任一环可独立重试。

10.2.3 学习流（天~周级，飞轮）

触发采集 → 回传入湖 → 索引筛选 → 数据集 → 训练 → 三级评测 → 模型 OTA 灰度 → 回到部署（7.8.1 十环节）。SLA：飞轮转速按任务族设定（7.8.2）。

三条流的隔离纪律：遥测流不承载任务语义、任务流不搬运字节、学习流不进实时链路——三句读图纪律（4.1.7）的数据流版。

10.4 六个 Ops：流水线体系

10.4.1 分工总表

Ops 对象 流水线核心 定义章节
DevOps/CI-CD 云端服务与端侧软件包 代码→测试→镜像/deb→GitOps 发布 存量 + 2.23
GitOps 云与 200 边缘集群 Git desired → Argo 拉取收敛 4.9.2
MLOps 数据集与训练 清单式数据集→训练 run→血缘 7.6
LLMOps Prompt/Agent/知识/记忆 Prompt 即制品+评测门禁+审计 4.10
RobotOps 端侧整机软件态 机型基线→16 步上机→OTA 四载荷→远程设备诊断 6.7 / 4.3
FleetOps 机队运营 调度/健康分/无人工闭单率/站点自治 SLA 4.7 / 4.9

RobotOps 与 FleetOps 是机器人域新增的两个 Ops——前者管「一台机器人的软件态」，后者管「一万台机器人的运营态」；其余四个是你的存量流水线换对象。

10.4.2 统一发布心法：一切皆制品、一切走灰度

六个 Ops 收敛于同一条纪律：服务镜像、端侧软件、固件、模型、配置、地图、Prompt、场景包、权限文件——全部是签名制品，全部走灰度与回滚（4.3 的纪律辐射全域）。发布系统只有一套心智，运营只学一次。

10.4.3 环境与晋级链

开发容器（第三篇）→ CI（Gazebo 仿真测试，8.2.2）→ 预发（沙盘推演，8.5.2）→ 影子（4.3.6）→ 灰度环 → 全量——六级晋级链覆盖代码、模型与配置三类变更，级级有门禁、级级可回滚。

10.5 落地路线图与组织

10.5.1 四阶段落地路线

阶段 周期 交付 对应
P0 骨架 1~2 月 接入+身份+遥测+基础 OTA（「看得见、升得了」） 1.2.9 顺序
P1 闭环 2~3 月 模型 OTA 最小闭环 + 触发回传 + 开环回放 4.3.10 / 7.7.5
P2 飞轮 3~6 月 数据引擎全量 + 三级评测 + Fleet 任务面 7.x / 4.7
P3 规模 持续 多站点边缘 + 安全全量 + 沙盘与 AI 面进阶 4.9 / 9.x / 8.5

每阶段独立可验收、独立产生价值——不做「两年后见」的大平台豪赌（8.2.5 同一哲学）。

10.5.2 组织映射

八平面 + 六 Ops 映射到团队：平台团队按平面分组（622 配比，1.7.6），数据/算法/安全横向协作，飞轮转速为三团队共同北极星（7.8.5）。参考架构同时是组织设计文档——康威定律主动用而非被动挨。

10.5.3 白皮书使用场景速查

对高管：10.0.2 总览图 + 10.5.1 路线 + 转速指标；对客户/竞标：四张部署图 + 安全架构总图（9.7.3）+ 自治 SLA；对团队：选型矩阵 + ADR 制度 + 4.11 Checklist；对候选人面试你：全书任何一章（第十二篇见）。

10.6 本篇总结

10.6.1 十条核心结论

  1. 参考架构四视图法：逻辑/部署/数据流/开发运维，争议先定视图。
  2. 八平面定版：接入/设备/OTA/数据/任务/AI/安全/可观测——安全与可观测独立成面。
  3. 四张部署图定物理落位：云端多活、站点 K3s、端侧三域隔离、全局四层拓扑。
  4. 三条主干流各守其位：遥测不载任务、任务不搬字节、学习不进实时。
  5. 选型矩阵 + ADR 制度：改选型有据可查，架构的一半价值在此。
  6. 六个 Ops，四旧两新：RobotOps 管一台机的软件态，FleetOps 管一万台的运营态。
  7. 一切皆制品、一切走灰度：九类制品一套发布心智。
  8. 六级晋级链：开发→CI 仿真→沙盘→影子→灰度→全量，级级门禁级级可回滚。
  9. 四阶段落地：骨架→闭环→飞轮→规模，每阶段独立可验收。
  10. 参考架构即组织设计：八平面分组 + 飞轮转速做跨团队北极星。
