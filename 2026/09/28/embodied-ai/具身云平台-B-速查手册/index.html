B.1 ECL v1 端云协议

B.1.1 主题树

主题格式：ecl/v1/{robot_id}/{kind}。p01 云端与 p06 ROS 2 云桥共同遵守，契约测试逐项比对。

kind 方向 载荷要点 QoS 说明
telemetry 上行 seq、stamp、位姿、电量、CPU、GPU 温度、关节最高温、错误码、模式、task_id、model_ver 1 云端按接收时刻判断新鲜度
event 上行 类型、级别、详情、时间 1 故障、急停、模式切换
status 上行 online / offline 1 上线发布；遗嘱发布 offline
shadow/reported 上行 当前值、liveliness_ok、rejected（逐项拒绝原因） 1 活性是在线判定第三信号
task/event 上行 task_id、state、stage、progress、detail 1 进度事件同时续租
shadow/delta 下行 desired_ver、delta 1 只含与回报不同的键
task/cmd 下行 task_id、type、params、lease_s、trace_id 1 云只下目标，不下动作

B.1.2 任务类型与阶段

类型 阶段 最低电量
patrol plan → move → inspect → report 0.30
move_to plan → move 0.15
pick_place plan → approach → grasp → place 0.30
charge move → dock → charge 0.00
calibrate warmup → sample → solve 0.20

B.1.3 影子可写字段

字段 目标节点（p06） 校验
report_hz state_aggregator 数值，0.2–10
speed_limit task_executor 数值，(0, 1.5]
mode task_executor auto / manual / maintenance
model_ver cloud_bridge 非空字符串，≤ 64 字符（真实切换由 OTA Agent 完成）

不在白名单的键回报 not writable，校验失败回报 validation failed。

B.2 状态机速查

B.2.1 在线状态

stateDiagram-v2
  [*] --> OFFLINE
  OFFLINE --> ONLINE: status=online 且遥测新鲜
  ONLINE --> DEGRADED: 遥测新鲜但机内活性异常
  DEGRADED --> ONLINE: 活性恢复
  ONLINE --> ZOMBIE: 连接在但遥测超过 stale_s
  ZOMBIE --> ONLINE: 遥测恢复
  ONLINE --> OFFLINE: 遗嘱 / status=offline
  ZOMBIE --> OFFLINE: 遗嘱
  DEGRADED --> OFFLINE: 遗嘱

只有 ONLINE 可以被派单；ZOMBIE 与 DEGRADED 进入告警；OFFLINE 由遗嘱触发。

B.2.2 任务状态

SENT → ACCEPTED → RUNNING → SUCCEEDED / FAILED / CANCELED；SENT → REJECTED；任意活动态租约到期 → RECLAIMED。活动态为 SENT、ACCEPTED、RUNNING；终态之后的任何事件一律忽略。

B.2.3 端侧 OTA Agent 状态

IDLE →（窗口满足）→ 预检 → 备槽预加载 → 自检 → OBSERVING（已切换）→ CONFIRMED（全量后确认）/ ROLLED_BACK（破线回切）；预检或自检失败 → FAILED（原槽保持）。

B.2.4 诊断工作流步骤

collect → rank → check → rerank → decide → report，每步完成即落盘；decide 的三种结果：auto（高置信且有低风险处置）、pending_review、human_approved / human_rejected。

B.3 命令速查

B.3.1 ROS 2（Jazzy）

目的 命令
列节点 / 话题 / 动作 ros2 node list、ros2 topic list -t、ros2 action list
看话题频率与带宽 ros2 topic hz /x、ros2 topic bw /x
看发布者订阅者与 QoS ros2 topic info /x --verbose
抓一条消息 ros2 topic echo /x --once
读写参数 ros2 param get /node p、ros2 param set /node p v、ros2 param dump /node
发送动作目标 ros2 action send_goal /ros_001/robot_task ecl_interfaces/action/RobotTask "{task_id: t1, type: move_to, params_json: '{}', lease_s: 30.0}" --feedback（p06 节点位于以机器人 ID 命名的命名空间下）
自检 ros2 doctor --report
录制与回放 ros2 bag record -s mcap /x /y、ros2 bag play <dir>
限制发现范围 export ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST
构建 colcon build --symlink-install，然后 source install/setup.bash

B.3.2 MQTT

目的 命令
启动 broker make broker-up（code/ 下，Docker 起 mosquitto，宿主机端口 23010）或 mosquitto -p 23010
订阅某台机器人全部主题 mosquitto_sub -h localhost -p 23010 -t 'ecl/v1/sim-001/#' -v
手工下发影子 mosquitto_pub -p 23010 -t ecl/v1/sim-001/shadow/delta -m '{"ver":2,"delta":{"report_hz":2.0}}'
看保留的在线状态 mosquitto_sub -p 23010 -t 'ecl/v1/+/status' -v -C 3

B.5 公式速查

B.5.1 常用计算

用途 公式 章节
推理时延预算 热稳态 P99 < 0.7 × 动作块时长（块时长 = 块长度 ÷ 执行频率） 6、13
双槽内存 2 × 单模型内存 ≤ 0.4 × 设备内存（经验值，留给感知与系统） 6、13
两比例 z 检验 z = (p₁ − p₂) / √(p̄(1 − p̄)(1/n₁ + 1/n₂))，p̄ 为合并比例 9、18
诊断打分 logit = ln(先验 / (1 − 先验)) + Σ命中权重 − 0.5 × Σ不成立权重；分数 = 1 / (1 + e^(−logit)) 11、21
回传带宽 每站日回传量 ÷ 夜间窗口秒数 × 8 = 所需 bps 12
片段价值 触发器权重 × (0.5 + 0.5 × 新颖性) × (1 + 标签稀缺度) 12、19
飞轮转速 部署完成时刻 − 首次触发时刻（按问题类型取中位数） 12、19
场景包角色 皮尔逊相关系数 ≥ 0.8 门禁；≥ 0.5 参考信号；否则冒烟 14

B.7 架构评审清单

B.7.1 按平面

平面 必问
接入 身份从产线来吗？在线判定几个信号？遗嘱在 connect 前设置吗？主题 ACL 是模板化的吗？
孪生 影子有白名单与范围吗？回报逐项说明拒绝吗？断线期间的变更会丢吗？
任务 有租约吗？长阶段续租吗？迟到事件如何处理？资源锁有 TTL 吗？避碰在本地吗？
OTA 四类载荷都签名吗？兼容矩阵在云端和端侧各查一次吗？门禁有对照组与显著性吗？何时释放旧槽？
可观测 三键由框架注入吗？顶层指标是作业质量吗？趋势告警覆盖渐进退化吗？
数据 有随机基线与分触发器配额吗？元数据先行吗？数据集不可变吗？统计量随清单吗？
模型 五元组齐全吗？评测对象就是发布对象吗？分组报告吗？场景包做过相关性校准吗？
Agent 有直控工具吗？参数白名单吗？人审通过时复检吗？环境文本当数据吗？审计防篡改吗？
安全 信任链到模型吗？密钥分用途吗？机内 SROS2 吗？安全参数受控吗？物理安全独立吗？

B.8 术语表

B.8.1 四十个术语

术语 解释
具身智能 能在物理世界感知、决策、行动的智能体
VLA 视觉-语言-动作模型：看图听指令，输出连续动作
动作块（chunk） 模型一次输出的一段连续动作，按执行频率逐步执行
动作头 VLA 中把理解变成动作的部分：token、回归、扩散或流匹配
快脑 / 中脑 / 慢脑 毫秒级控制 / 百毫秒级 VLA / 秒级规划与 Agent
ROS 2 机器人软件框架，基于 DDS 的发布订阅中间件
DDS 数据分发服务：ROS 2 的底层通信标准
QoS 服务质量策略：可靠性、持久性、历史深度、截止时间等
节点 / 话题 / 服务 / 动作 ROS 2 的进程单元 / 流式数据 / 请求应答 / 长任务（带反馈与取消）
Jazzy / Lyrical ROS 2 的两个 LTS 发行版（Ubuntu 24.04 / 26.04 基线）
JetPack NVIDIA Jetson 的系统软件包（含驱动、CUDA、TensorRT）
引擎矩阵 模型编译产物按机型 × JetPack × 精度组织
热稳态 P99 设备温度稳定后的推理时延 99 分位
云桥 机器人对外唯一通道，类比车联网 TBox
ECL v1 本书定义的端云协议（Embodied Cloud Link）
设备影子 期望态、回报态与差异（delta）的三元组
三信号在线判定 连接、遥测新鲜度、机内活性
ZOMBIE 连接在但遥测不新鲜：假死
任务租约 任务的“保质期”，进度事件续租，到期回收
L3 平台任务 云端下发的带 ID、租约、trace 的任务，不含动作细节
VDA 5050 基于 MQTT + JSON 的移动机器人调度接口标准
Open-RMF 多厂商机器人机队的互操作框架
四载荷 固件、模型、配置、技能
双槽热切换 新模型预加载到备槽，动作块间隙原子切换
安全版本号 防止降级到有漏洞版本的单调版本号
灰度环 内部、单站点、多站点、半量、全量
作业质量门禁 以成功率、介入率、急停为指标的灰度门禁
无人工闭单率 无任何人工介入即完成的任务占比
触发五件套 故障、介入、低置信、分歧、新颖性
元数据先行 事件事实先入索引，片段字节后到
以景搜景 用场景向量检索相似片段
质量漏斗 机械质检、内容质检、价值评分、人工审核
数据集清单 不可变的片段引用 + 统计量 + 划分 + 数据卡
飞轮转速 从线上问题到针对性模型上线的天数
五元组 基座、数据集哈希、代码提交、配置、种子
三契约 观测、动作、运行
场景包 版本化的仿真评测场景集合
安全笼 Agent 工具调用必经的检查链
环境注入 物理世界中的文字被当作指令的攻击
SROS2 ROS 2 基于 DDS Security 的认证、访问控制与加密能力
