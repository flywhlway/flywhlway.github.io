C.7 维护本书

C.7.1 工具与流程

文件 作用
tools/stats.py 统计字符数、三级标题、Mermaid 与 PlantUML 数量；检查代码块闭合、图类型、链接有效性
tools/gen_mapping.py 附录 A 的唯一数据源：修改映射请改这里，再重新生成
code/Makefile make test 跑全部测试、make verify 做多进程全家桶联调
每个工程的 tests/ 修改代码后必须全绿；书中引用的代码片段与剧本输出需同步更新

更新流程：改代码 → 跑测试 → 跑剧本 → 同步书中片段与输出 → 跑 stats.py → 记录变更。本书编写过程中，这个流程发现过“书中描述与代码不一致”的问题（例如离线队列语义、附录 A 的占比文案），它和测试一样重要。
