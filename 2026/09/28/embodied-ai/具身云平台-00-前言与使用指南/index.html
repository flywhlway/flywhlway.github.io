前言与使用指南

所有工程共享一套端云协议 ECL v1（Embodied Cloud Link）…

Flywhl 6 分钟 发布于 2026.09 #具身智能#学习路线

信息截止：2026 年 9 月下旬。具身智能领域月月有新模型、新产线、新融资，本书对“事实类内容”（模型版本、硬件型号、产业数字）均标注时间口径；对“方法类内容”（架构、工程纪律、迁移方法）则力求三五年不过时。

0.1 为什么要写 2026 版

0.1.1 三个月里行业变了什么

2026 年 7 月我们完成过一版 15 篇的《Embodied AI Engineering Handbook》。短短三个月，至少五件事让它需要重写而不是修补：

  1. ROS 2 进入新 LTS 周期：Lyrical Luth 于 2026 年 5 月发布，支持到 2031 年，但它的一级平台是 Ubuntu 26.04；而 Jetson Thor 的 JetPack 7 仍基于 Ubuntu 24.04——端侧选型从“无脑 Jazzy”变成了一道需要讲清楚的判断题。
  2. 基础模型从“能跑”走向“能用”：π0.7 展示了对未训练任务的组合泛化，GR00T N1.7 以 Apache 2.0 开放并直接进入 LeRobot 工作流，Gemini Robotics ER 2 经公开 API 可用——“云端大脑 + 端侧小脑”的分工从论文图变成了可采购的能力。
  3. 端侧算力分层完成：Thor 家族从 T5000、T4000 延伸到 2027 年供货的 T3000/T2000，人形与移动机器人都有了对应的“机器人主控”档位。
  4. 数据成为第一瓶颈：业内把 2026 年称为“数据规模化元年”，百万小时级采集成为入局门槛，同时开始从“训练场遥操作数据”转向“真实场景作业数据”——这恰恰是平台工程师的主场。
  5. 车企集体“造人”：约二十家主流车企通过自研、合资、孵化进入具身智能，小鹏 IRON 产线已启用，特斯拉改造产线生产 Optimus。车联网架构师从“跨界者”变成了“顺位继承者”。

0.2 这本书写给谁

0.2.1 最适合的读者

  • 有 5 年以上物联网 / 车联网 / 云平台经验、零机器人背景的架构师与高级工程师；
  • 做过 OTA、远程诊断、设备接入、数据平台、Agent 平台中的一两样，想把能力迁移到具身智能；
  • 正在车企、机器人公司、云厂商内部评估“要不要做机器人云平台 / 数据平台”的技术负责人。

0.2.2 不适合的读者

  • 想系统学习机器人学（动力学推导、最优控制、SLAM 数学）的同学——请读专门教材，本书只给平台架构师够用的“最小知识集”；
  • 想训练 SOTA 模型的算法研究者——本书讲的是模型工厂，而不是模型本身。

0.4.3 验证口径说明

代码分两轮验证。第一轮在 Linux 沙箱中：p01–p05 的测试全部通过，p01 用真实 Mosquitto 做了端到端联调，全家桶链路以多进程方式跑通；p06 因沙箱无法安装 ROS 2，只做了静态校验与协议契约测试。第二轮（2026-09-28）在本地真实 Docker 镜像中做全量端到端验收（cd code && make e2e-docker）：python:3.12-slim 测试镜像内跑全部测试与剧本，ros:jazzy-ros-base 构建的 p06 镜像内跑 rclpy 运行时测试，再用 compose 拉起全家桶与 p06 做场景验收——这一轮发现并修复了 p06 在真实 ROS 2 中根本无法启动等缺陷（第 22 章 22.5.5、第 23 章 23.6.2）。所有宿主机端口使用独占号段 23xxx（code/ports.env），不与你机器上的其它服务冲突。能验证什么、不能验证什么，书里都写明。

0.5 本书约定

0.5.1 章节固定模块

每章正文之后固定五个模块，便于快速回看：

  • 🚗→🤖 迁移对照：把本章概念对齐到你熟悉的车联网对应物；
  • ⚠️ 一线踩坑：典型问题模式——现象、根因、对策（均为行业常见模式的归纳，不指向具体公司）；
  • 🛠️ 动手练习：对应代码工程中的具体任务；
  • 🎯 面试与评审要点：这一章最常被问到、最常在架构评审中被挑战的问题；
  • 📝 本章卡片：可直接复制进 Obsidian 的 **双链卡片**。

0.5.2 用语约定

用语 含义
本体 机器人的物理身体（底盘、手臂、手、传感器、电池）
端侧 / 边缘 / 云端 机器人主控 / 站点机房 / 中心云，三者边界见第 7 章
站点（Site） 一个工厂、仓库、门店或园区，≈ 车联网里的“区域 + 场站”
制品（Artifact） 一切可签名、可版本化、可灰度的下发物：固件、模型、配置、技能、地图
慢脑 / 中脑 / 快脑 秒级规划（LLM/VLM）/ 5–50Hz 策略（VLA）/ 百赫兹以上控制与安全

0.5.3 如何配合 Obsidian 使用

把 book/ 目录整体放进 Obsidian 库：章节文件之间用相对链接跳转，每章末尾的 **卡片** 会在关系图谱中自动连成网络。建议建立三个视图：按章阅读、按卡片复习（每周回看被引用最多的卡片）、按“迁移对照”检索（附录 A 做为索引页置顶）。

0.6 致读者

你不需要从零学成机器人专家。真正稀缺的，是能把设备接入、OTA、数据闭环、诊断、Agent 平台这些“车联网十年沉淀”连成一个让机器人越用越聪明的飞轮的人。本书的全部内容，都在帮你把已经拥有的能力，重新接到一条更长的价值链上。
