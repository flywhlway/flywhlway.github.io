1. 基础：Glob 通配符 vs 正则表达式

这是所有查找工具的认知地基。90% 的「为什么我的命令没匹配上」都源于混淆了这两套语法。

1.1 Glob（Shell 通配符）

Glob 由 Shell 展开，在命令执行前就已经变成了文件名列表。

语法 含义 示例 匹配
* 任意长度字符（不含 /，默认不含开头的 .） *.log app.log
? 恰好一个字符 log?.txt log1.txt
[abc] 字符集合中的一个 log[123].txt log2.txt
[a-z] 字符范围 [a-f]*.c boot.c
[!abc] / [^abc] 排除 log[!0].txt log5.txt
{a,b,c} 花括号展开（Bash/Zsh，非 POSIX glob） file.{c,h} file.c file.h
** 递归子目录（需 globstar） **/*.py a/b/c.py

1.2 正则表达式三大方言

方言 全称 使用者 特点
BRE Basic Regular Expression grep（默认）、sed（默认）、find -regex(GNU 近似) `+ ? { } ( )
ERE Extended Regular Expression grep -E、egrep、awk、find -E(🍎) 元字符不需要转义

需求 BRE ERE PCRE
一个或多个 \+ + +

执行模型：find 遍历目录树，对每一个文件依次求值表达式；表达式返回真则继续下一个，最终若无显式动作则执行 -print。

2.5 按时间查找（最容易搞错的部分）

三种时间戳：

缩写 全称 触发条件
a (atime) access time 文件被读取
m (mtime) modify time 文件内容被修改
c (ctime) change time inode 元数据变更（权限/属主/硬链接数/内容）

两种粒度：-Xtime N（单位：24 小时）、-Xmin N（单位：分钟）。

数值语义（必背）：

写法 含义
-mtime 0 距今 0~24 小时内修改
-mtime -7 最近 7 天内修改（小于 7×24h）
-mtime +7 7 天以前修改（大于 7×24h）
-mtime 7 恰好 7~8 天前那一个 24 小时窗口

3.2 macOS：mdfind（Spotlight 命令行）🍎

macOS 的 locate 默认未启用，但 Spotlight 索引更强大——它索引了文件内容和元数据。

⚠️ mdfind 只搜索 Spotlight 索引范围内的路径。系统目录、被排除的卷、.noindex 目录不会被搜到。

5. ripgrep (rg)：现代默认选择

为什么 rg 应该成为你的默认：Rust 编写、正则引擎基于有限自动机（无回溯爆炸）、多线程遍历、自动尊重 .gitignore、自动跳过隐藏文件与二进制文件、自带文件类型过滤。

5.1 开箱即用

对比 grep -rn：无需任何选项，默认递归、默认行号、默认彩色分组、默认跳过 node_modules/.git/二进制文件。

xargs 报「参数过长」 单批参数超限 xargs -n 100
脚本因 grep 无匹配退出 set -e + 退出码 1 grep ... || true
符号链接无限循环 -L 跟随了环状链接 去掉 -L，或 find -L ... -maxdepth N
扫全盘卡死 爬进 /proc /sys 或 NFS 加 -xdev

🔒 安全建议

  1. 生产环境的批量操作必须两步走：先输出清单落盘，人工审核后再按清单执行。
  2. 在脚本中永远使用 -print0 | xargs -0，杜绝文件名注入。
  3. -execdir 优于 -exec：避免在被攻击者控制的目录中执行命令时的路径歧义。
  4. 敏感信息搜索结果不要写入日志或粘贴到聊天工具——搜出来的密钥本身就是泄露载体。
  5. sudo find / 前先 -xdev，防止跨挂载点误删网络存储数据。
